# 交互与验收说明

## 0.4.2 交互

- 当前会话独立解析工作区；预览的源文件地址可以来自旧会话，新增批注的目标始终取 `sidebarRight.mounted`。预览上下文由可见面板中的文件入口元数据及实际交互确定，避免 keepMounted 的隐藏面板抢占全局状态。
- TXT/Markdown/源码等预览支持选字，文件代码查看器内 readonly contenteditable 也可使用；普通表单仍忽略。文字索引跨 DOM 片段，保存归一化偏移、前后文和可选 PDF 页码，Range 映射回实际文本。找不到或未渲染的引用不显示假页边编号。
- 输入占位统一为「写下批注」，空历史不显示说明，也不把长路径塞进输入框。
- macOS 桌面首次加载通过 `shortcuts.edit` 将 `workspace.files` 改为 Cmd+O，再将批注改为 Cmd+P。按 revision 写入，启动期 stale/not-ready 会有限重试；第二步失败回退文件键，成功留本地备份和一次性完成标志。后续手动改键不被每次启动覆盖。网页端受宿主约束保留下面的组合键。
- 其他会话的未发送批注只能显式「移到本会话」，不会因打开旧文件而自动混入。

- 文字选区：点击实色「批注」按钮或使用 `⌘⇧E` / `Ctrl+Shift+E`。快捷键由 DSH 命令表注册，支持宿主改键/关闭；Linux 网页端默认不绑定；Web 预览内部吃掉冒泡事件时，捕获监听仍按同一有效绑定响应。
- 整批提交：评论输入框内 `⌘Enter` / `Ctrl+Enter` 保存当前评论再提交；编辑已有待发送评论时同样适用。预览中聚焦非输入控件时可提交已有批注。原生主输入框保留 DSH 自己的发送规则；列表「发送全部批注」显式走原生 queue 提交，不直接调用模型。
- 普通 Enter 只保存；保存键悬停说明快捷键，输入框不再显示 Enter 提示。保存与取消等大，保存为蓝色。
- 框选结束的虚线框保留到保存/取消，滚动/缩放时按载体坐标重画并裁剪到可见区。
- 再次点同一侧栏批注按钮可收起历史卡片。
- 全屏标记层使用 `-webkit-app-region: initial !important`，只有局部交互层使用 `no-drag`，避免阻挡窗口顶部拖动。

## 本轮待发送批注

保存文字、区域或整文件批注后，记录按 `sessionId` 出现在 `conversation.input.dock`。这个列表与原生主输入框相邻，不依赖文件侧边栏是否展开。

列表允许折叠、编辑评论、移除和打开源文件。区域批注有裁剪图时显示缩略图；重载后通过 `POST crop-preview` 读取已保存的 PNG。

编辑时须先保存或取消，再发送；输入法组字期间不会误触保存。正在提交的批注锁定编辑与移除，后续新批注仍可加入下一轮。

## 原生发送

插件为当前会话加入一枚「文件批注」原生引用。用户输入的文字和其他引用保留，插件不把完整批注段落预先塞进文字草稿。

DSH 的发送按钮和 Enter 共用以下流程：

1. 原生引用 codec 等待当前批注裁图保存完成；
2. 按当前会话截取一批不可变的未发送记录，生成模型文本；
3. DSH 将引用展开，与文字、原有附件和其他引用一起提交；
4. 插件观察该会话公开 `Session.prompt()` 的结果；宿主确认 `ok: true` 后，才设置这批记录的 `sentAt`；
5. 拒绝、网络失败或序列化失败时保留待发送批注，由 DSH 恢复原文字草稿和引用。

`sentAt` 只表示消息获准接收；AI 随后的执行失败不应把已经提交的消息当作未发送消息再自动发一次。

只有批注、没有额外文字时，原生引用也能启用发送按钮。保存批注本身不会自动触发发送。

## 会话、快照和恢复

- 删除蓝色「文件批注」引用会把当前批记录设为 `detached: true`，保留历史而不加入本次发送；刷新不补回。在历史点击「加入待发送」可逐条恢复。原生提交的非 plain 阶段清空不触发移除。
- Better Sidebar 的文件查看器通过公开注册表增加批注工具条；TXT、JSON 等 CodeMirror 内容区可以选字批注。HTML 默认在渲染层选字批注，支持「选元素」和元素内「框选」；移除「纯文字」切换入口，原编辑器保持挂载、沙箱权限保持原状。文字与代码选区的「批注」和「添加到对话」合并显示，添加操作沿用原有文件及行号上下文。

- 当前会话的列表与历史查看范围独立；「全部会话」不会改变本轮提交内容。
- 一次提交只确认它序列化时的快照；提交期间新建的记录保留到下一批。
- 移除最后一条批注只移除插件自己的引用，保留用户文字和其他上下文。
- 重载时将持久化的自有引用文本恢复成原生引用，避免追加重复引用。
- 宿主读取返回时，合并读取期间的本地新增、编辑和删除，避免覆盖刚保存的批注。
- 卸载时撤销监听和每个会话的方法包装；正在发送时关闭 DSH 仍受宿主自身生命周期约束。

## 文档预览

文字选区先显示「批注」操作，点击才打开输入条。Enter 保存、Esc 取消；新选区不替换已打开的草稿。

框选接收层只覆盖 PDF、图片或 HTML iframe 的可见部分，使用 Pointer Events 和 pointer capture。区域坐标归一化到 0–1；PDF 页码读取 `[data-pdf-page]`。

收起和重新展开右侧边栏、切换标签页或切换会话时保留批注。确认关闭单个文件预览后，清除该文件的 JSON/localStorage 记录、待发送卡片、蓝色引用和缩略图缓存，10 秒内可撤销。未发送截图在撤销期后收集，发送中的记录待宿主结果确定，消息引用图片通过 .sent 标记保留。

HTML iframe 无同源权限，因此没有裁剪图；PDF 和图片保留 PNG 裁剪图路径。批注不会跟随文件内容改动自动迁移。

## 历史与整文件批注

预览头部入口显示历史，并保留整文件批注输入。当前会话的未发送记录在主输入框上方管理，历史不再提供单独的「发给 AI」动作。

## 开发验收

```sh
node --test test/verify.mjs
node --test test/host.test.mjs
```

必须同时验证真实 DSH 界面：保存不发送、仅批注发送、文字+Enter、故障恢复、编辑/移除、收起侧边栏、重载和会话切换。使用合成文件和本地模拟模型，避免将测试请求发给真实模型。

## HTML 元素锚定（0.5.0）

Better Sidebar 的脚本沙箱预览通过一次性 MessageChannel 接入页面几何与选区。预览 URL 仍经原宿主的工作区校验，保留 iframe sandbox 与 object-src 限制，不提供同源访问。网页数据只能提出选区或位置；保存与发送仍在父应用的批注输入条和原生 composer 完成，普通 window.postMessage 不能保存或发送批注。

`htmlAnchor` 记录元素 selector、tag、文字摘要；文字批注附归一化偏移与前后文，框选附元素内部内容坐标。iframe 内部监听文档/嵌套 scroll、resize 和 DOM 变化，重新计算并裁剪 Range/元素矩形，再换算到父预览坐标。元素不匹配或离屏时隐藏标记。MessagePort、观察器、frame load 监听在卸载或预览移除时清理；导航离开原文件后停止定位。

发送时同时提供文件路径、CSS 选择器、选中文字/元素文字与评论。旧版 HTML 视口记录没有可恢复的 DOM 位置，不猜测迁移；重新选取后才能跟随元素。

HTML 的选择网页元素入口为图标，开启时变蓝，悬停网页元素会显示边框，Esc 退出。旁边小箭头菜单提供框选区域；原批注数量和历史入口保持原样。PDF 手动开启框选后，保存或取消批注可连续框选；编辑批注期间暂停框选，Esc 退出，切换文件或会话也会退出。

PDF 工具条使用虚线框图标，开启时为蓝色。图标旁小箭头内的「打开 PDF 时默认框选」复选项会记住选择，默认关闭。开启后当前和以后打开的 PDF 可直接框选；Esc/手动退出仅作用于本次查看，滚动或页面懒加载不会重新开启。PDF 框选不再覆盖滚动区域，连续框选时支持滚动、滚动条与触控板翻页。
